# Medición de Distancia con HC-SR04

Implementación de medición de distancia utilizando el sensor ultrasónico HC-SR04 con Arduino.

---

## Descripción

Este proyecto permite medir distancias mediante el uso de ondas ultrasónicas.

---

## Funcionamiento

El sensor emite un pulso ultrasónico y mide el tiempo que tarda en regresar.

Distancia = (tiempo × velocidad del sonido) / 2
